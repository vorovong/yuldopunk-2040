## D-001 — Separate Repository

**Date**: 2026-06-10  
**Status**: Accepted

### Context

The concept started in the knowledge store and Beomseok already created a presentation-oriented repository. The playable product needs its own development loop, deployment target, and agent harness.

### Decision

Create a separate repository named `yuldopunk-2040`.

### Consequences

- The knowledge store remains the concept archive.
- Beomseok's repository remains useful reference material.
- This repository becomes the product implementation home.

## D-002 — Phase 1 Timeframe

**Date**: 2026-06-10  
**Status**: Accepted

### Context

Earlier goal drafts mixed pre-construction, construction, and post-completion town operation features. That scattered the gameplay objective and made the scores inconsistent.

### Decision

Phase 1 focuses only on the founding/construction episode: `첫 겨울까지 180일`.

### Consequences

- Scores must evaluate founding readiness, winter survivability, budget, construction progress, and social consent.
- Post-completion operation features are explicitly out of scope.
- The first playable product has a clear player objective and time pressure.
